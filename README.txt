KIMIE MACROBOT V1.0 - Android project

This is a genuine Android application project, not a compiled APK.
It embeds a fully offline manual booking filter UI. No Grab integration, auto-click,
accessibility service, screen capture, or automatic booking acceptance.

BUILD WITH GITHUB ACTIONS (phone browser):
1. Create a GitHub repository.
2. Upload the project files keeping the .github/workflows/build-apk.yml path.
3. Go to Actions > Build Android APK > Run workflow.
4. Download the KIMIE-MACROBOT-debug-APK artifact after the workflow succeeds.
5. Unzip it, then install app-debug.apk on Android after verifying the source.

This build has not been compiled or tested in the current environment.
